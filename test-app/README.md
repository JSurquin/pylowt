# 📝 Todo List Vue.js

Une application de gestion de tâches simple et élégante construite avec Vue.js 3.

## ✨ Fonctionnalités

- ✅ Ajouter des tâches
- ✅ Marquer les tâches comme complétées
- ✅ Supprimer des tâches
- ✅ Modifier des tâches (double-clic)
- ✅ Filtrer les tâches (Toutes / Actives / Complétées)
- ✅ Tout cocher / décocher
- ✅ Supprimer toutes les tâches complétées
- ✅ Sauvegarde automatique dans le localStorage
- ✅ Interface responsive et moderne
- ✅ Animations fluides

## 🚀 Utilisation

1. Ouvrez le fichier `index.html` dans votre navigateur
2. Commencez à ajouter des tâches !

## 💡 Astuces

- Appuyez sur `Entrée` pour ajouter rapidement une tâche
- Double-cliquez sur une tâche pour la modifier
- Utilisez les filtres pour organiser vos tâches
- Vos tâches sont automatiquement sauvegardées dans le navigateur

## 🛠️ Technologies

- Vue.js 3 (via CDN)
- HTML5
- CSS3
- LocalStorage API
