# QCM Module 6
## Tests avec Vitest

---

# Question 1 - Installation

Comment installer Vitest ?

A. `npm install vitest`
B. `npm install -D vitest`
C. `npm install test`
D. `npm install jest`

**Réponse:** B

---

# Question 2 - Test runner

Quelle commande pour lancer les tests ?

A. `npm test`
B. `npm run test`
C. `vitest`
D. Toutes les réponses

**Réponse:** D

---

# Question 3 - Assertions

Quelle assertion vérifie l'égalité stricte ?

A. `expect(a).toEqual(b)`
B. `expect(a).toBe(b)`
C. `expect(a).toStrictEqual(b)`
D. `expect(a).equals(b)`

**Réponse:** B

---

# Question 4 - Mount composant

Quelle fonction pour monter un composant Vue ?

A. `render(Component)`
B. `create(Component)`
C. `mount(Component)`
D. `new Component()`

**Réponse:** C

---

# Question 5 - Props

Comment passer des props dans un test ?

A. `mount(Comp, { props: {...} })`
B. `mount(Comp).setProps({...})`
C. `mount(Comp, {...})`
D. A et B

**Réponse:** D

---

# Question 6 - Events

Comment vérifier qu'un événement a été émis ?

A. `wrapper.events('click')`
B. `wrapper.emitted('click')`
C. `wrapper.emit('click')`
D. `wrapper.hasEmitted('click')`

**Réponse:** B

---

# Question 7 - Mocks

Comment mocker une fonction avec Vitest ?

A. `mock(fn)`
B. `vi.fn()`
C. `jest.fn()`
D. `spy(fn)`

**Réponse:** B

---

# Question 8 - Coverage

Comment générer un rapport de coverage ?

A. `vitest coverage`
B. `vitest --coverage`
C. `npm run test:coverage`
D. B et C

**Réponse:** D

---

# Question 9 - AAA Pattern

Que signifie AAA ?

A. Always All Assertions
B. Arrange-Act-Assert
C. All Async Actions
D. Auto Await Assert

**Réponse:** B

---

# Question 10 - Bonnes pratiques

Que doit-on tester ?

A. L'implémentation
B. Le comportement
C. Le style CSS
D. Les imports

**Réponse:** B
